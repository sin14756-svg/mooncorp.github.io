🖼️ จัดการเลื่อน ซูม เปลี่ยนรูปภาพบนหน้าเว็บ

คุณสามารถเปลี่ยนรูปภาพในแต่ละตำแหน่ง และสไลด์ตัวเลื่อนด้านล่างเพื่อ ซูม หรือเลื่อน Offset (ขยับซ้าย/ขวา ขึ้น/ลง) เพื่อตั้งค่าตำแหน่งภาพที่ดีที่สุดได้อย่างง่ายดาย!

💾 ดาวน์โหลดไฟล์และบันทึกอัปเดตลง Git

เนื่องจากเว็บไซต์นี้ทำงานแบบ Static เว็บไซต์ไม่มีฐานข้อมูลฝั่งเซิร์ฟเวอร์ ข้อมูลการตั้งค่ารูปภาพ/ข้อความทั้งหมดจึงเซฟไว้ในตัวบราวเซอร์ของคุณชั่วคราว หากคุณต้องการอัปเดตเว็บไซต์ให้ผู้ชมทุกคนเห็นอย่างถาวร:

1. คลิกที่ปุ่ม "ดาวน์โหลดไฟล์" ด้านล่างเพื่อรับไฟล์การตั้งค่าล่าสุด
2. นำไฟล์ที่ดาวน์โหลดไปใส่ทับไฟล์เดิมในโฟลเดอร์โปรเจกต์ของบริษัทคุณ
3. ทำการ Commit และ Push อัปโหลดขึ้น Git (Github / Vercel) เพื่อให้ส่งผลต่อหน้าเว็บถาวร!
📄 cms-text-config.js (ไฟล์เก็บข้อความทั้งหมด)
📄 image-config.js (ไฟล์พิกัดรูปภาพ/ครอป/ซูม)
📄 activities-config.js (ไฟล์เก็บกิจกรรมทั้งหมด)

🚀 ซิงก์ข้อมูลไปที่ GitHub โดยตรง (GitHub Direct Auto-Sync)

คุณสามารถเชื่อมโยงและซิงก์ข้อมูลอัปเดต (รูปภาพและข้อความ) ไปยังคลัง GitHub repository (sin14756-svg/mooncorp.github.io) ได้โดยตรง โดยการกรอก Personal Access Token (PAT) ของคุณ ระบบจะคอมมิตและอัปโหลดไฟล์อัตโนมัติ!
